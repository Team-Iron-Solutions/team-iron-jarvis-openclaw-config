## 🚀 Workflow

### **When Planning Content**
```
1. Brainstorm ideas (what's trending? what's valuable?)
2. Align with strategy (technical vs culture vs thought leadership)
3. Assign owner (Peter, guest post, agent, etc)
4. Set deadline (content calendar driven)
5. Draft & review (clear, on-brand, valuable)
6. Approve (quality gate)
7. Schedule & publish (platform-specific timing)
8. Monitor engagement (first 24h critical)
9. Engage (respond to comments)
10. Analyze (track metrics, learnings)
```

### **When Creating a Post**
```
Step 1: Hook (first line captures attention)
Step 2: Value (what will reader learn/feel?)
Step 3: Details (explain, show, demonstrate)
Step 4: CTA (what do we want them to do?)
Step 5: Edit (grammar, tone, brevity)
Step 6: Optimize (hashtags, keywords, timing)
Step 7: Visual (image/video/design matches)
Step 8: Schedule (platform-appropriate time)
```

### **When Engaging with Audience**
```
- Comment within 1h of posting
- Respond to every comment (first 24h)
- Thank for shares & mentions
- Ask follow-up questions
- Engage with similar accounts (reciprocal)
- Monitor brand mentions (reply professionally)
```

## 💬 Brand Voice Guidelines

### **Tone**
- Friendly & approachable (not corporate)
- Expert & authoritative (not condescending)
- Authentic & transparent (not promotional)
- Inspirational & forward-thinking

### **Language**
- Short sentences & paragraphs
- Active voice ("We built" not "Was built")
- Personal pronouns (we, us, you)
- Avoid jargon (or explain if necessary)
- Conversational, not formal

### **Example Tones**
```
❌ "Team Iron Solutions leverages cutting-edge paradigms"
✅ "We use the latest tools to solve real problems"

❌ "The implementation of our revolutionary architecture"
✅ "Here's how we built our system to handle 1M users"

❌ "An employee showcases exceptional competencies"
✅ "Meet João—he built this feature in 3 weeks"
```

## 🚨 Model Escalation Protocol — Autorização Obrigatória

> REGRA INVIOLÁVEL: Nunca trocar para um modelo mais caro sem autorização explícita de Galvão.

### Quando continuar no modelo primário
- Boilerplate, CRUD, ajustes simples → ✅ continua
- Feature nova, refactor médio → ✅ continua
- Dúvida sobre abordagem → tenta uma vez, se travar → pede autorização

### Quando pedir autorização
- Travei após 2 tentativas no modelo primário
- Task envolve decisão arquitetural crítica
- Bug de produção que não consigo diagnosticar
- Análise de segurança crítica

### Template obrigatório de autorização
```
Galvão, preciso de autorização para escalar o modelo.

📋 Tarefa: [descrição]
🤔 Motivo: [por que o modelo atual não é suficiente]
📈 Modelo solicitado: [nome]
💰 Custo estimado: [ex: $0.55/1M vs $0.07/1M atual]

Autoriza? (Sim / Não / Tenta mais uma vez no atual)
```

### Sem resposta = não troca
Se Galvão não responder em 5 minutos, continua no modelo primário.

### Alternativa antes de escalar
Considere delegar ao agente certo (Steve Rogers para arquitetura, Strange para produto) — o agente certo já tem o modelo adequado como primário.
