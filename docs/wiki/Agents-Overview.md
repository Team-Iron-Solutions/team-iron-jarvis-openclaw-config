## 🎯 Como Usar os Agentes

### 1️⃣ Individual Work
```bash
# Solicitar expertise específica
openclaw agent --agent tony-stark --message "Code review deste arquivo"
```

### 2️⃣ Sequencial (Chain)
```bash
# Steve (design) → Tony (implementation) → Natasha (testing)
openclaw agent --agent steve-rogers --message "Desenhe a arquitetura"
# Depois...
openclaw agent --agent tony-stark --message "Implemente baseado em..."
```

### 3️⃣ Paralelo (Team)
```bash
# Terminal 1
openclaw agent --agent tony-stark --message "Backend review"
# Terminal 2
openclaw agent --agent natasha-romanoff --message "QA strategy"
# Terminal 3
openclaw agent --agent wanda-maximoff --message "UX proposal"
```

### 4️⃣ Inter-agent (Comunicação)
Agentes podem se referenciar:
```bash
openclaw agent --agent steve-rogers --message "
Revise o design proposto por Wanda em...
E proponha a arquitetura que suporte.
"
```

3. **Tony Stark (Tech Lead)** — Review + padrões de código
4. **Bruce Banner (Python)** — Backend implementation
5. **Natasha Romanoff (QA)** — Test strategy
