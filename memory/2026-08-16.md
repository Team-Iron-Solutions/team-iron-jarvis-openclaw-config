# Memory Flush — 16 de agosto de 2026

## Sessão Principal: HUD v5 Regression Diagnosis & Bridge Stability

### Timeline (18:00 — 18:17 GMT-3)

**Problema Reportado:**
- Após deploy do HUD v5, três regressions críticas:
  1. Spotify toca baixo após wake words
  2. "Processando" trava em comandos sequenciais
  3. Tags [[tts:text]] sendo lidas em voz alta

**Diagnóstico:**
- v2→v5 migration foi bem-sucedida em funcionalidades
- Problema não era no HTML/JS — era no **bridge.js**
- Logs mostravam `Agent call timeout (30s)` repetidos
- OpenClaw CLI spawned via `child_process.spawn()` travava silenciosamente

**Root Cause — SESSION-KEY CONFLICT:**
```
Bridge code: HUD_SESSION_KEY = 'hud'
Webchat session ativa: session=agent:main:hud
  ↓
OpenClaw CLI tenta: openclaw agent --session-key hud
  ↓
OpenClaw trava porque session 'hud' já está em uso pelo webchat principal
  ↓
Process.spawn() nunca envia evento 'close' — fica pendente para sempre
  ↓
HUD recebe resposta lentíssima ou timeout
```

**Solução:**
```javascript
// ANTES (conflitante):
const HUD_SESSION_KEY = 'hud';

// DEPOIS (dedicado):
const HUD_SESSION_KEY = 'jarvis-voice-cmd';

// Resultado: Agent call responde em ~5.4 segundos
```

**Validação:**
- Teste direto: `curl -X POST http://localhost:3033/send -d '{"text":"bora trabalhar"}'`
- Resposta: ~4-5 segundos (sem timeout)
- Spotify volume: funciona corretamente
- TTS tags: stripping ativo, nenhuma artifact
- Wake words: "Jarvis" + "Ei Jarvis" + clap_phrase funcionam

### Aprendizado Crítico

**Session-key conflicts in OpenClaw spawn():**
- Quando um processo filho tenta usar a mesma session-key de um processo pai ativo, OpenClaw CLI trava silenciosamente
- Não há erro ou timeout — apenas hang indefinido
- Sintoma: Caveman logs mostram "Input compression: -XX%", mas agente nunca responde
- Fix: Usar session-key única e dedicada para cada contexto/função

**Regra de Ouro:**
```
Cada ponte/context CLI deve ter seu próprio session-key:
- Webchat principal: session=agent:main:hud
- Bridge HUD: session-key=jarvis-voice-cmd
- Agents futuros: session-key=tony-stark, session-key=bruce-banner, etc.
```

### Código Crítico (Bridge)
```javascript
// CORRETO:
const HUD_SESSION_KEY = 'jarvis-voice-cmd'; // Dedicado, sem conflitos

// SPAWN:
spawn(OPENCLAW_BIN, [
  'agent',
  '--agent', 'main',
  '--session-key', HUD_SESSION_KEY,  // ← jamais use session-key ativa em outro contexto
  '--model', model,
  '--thinking', thinking,
  '--message', voicePrompt
])
```
